# OTA 更新实施计划

## 1. 统一版本与后端接口

- 新增根目录 `VERSION` 并让配置读取它。
- 新增公开 `/api/version`。
- 新增 GitHub Latest 服务、缓存、版本比较和 admin status/run 路由。
- 添加 ROOT 权限、参数固定、并发锁和日志状态。

## 2. 前端版本与管理后台

- 页脚读取 `/api/version`，显示当前版本并定时刷新。
- 管理后台加入 OTA 标签，展示当前/Latest 版本、检查时间、错误和发行版链接。
- ROOT 显示升级按钮及执行状态；管理员只读检查结果。

## 3. 迁移脚本

- 重构 `dev.sh` 为可复用的非交互入口。
- 让 `setup.sh` 调用统一初始化流程。
- 新增 `Update.sh`，实现备份、tag 切换、安装、迁移、强制重启/健康检查和失败恢复。
- 补充 `.env.example` 和运维文档说明。

## 4. 验证与交付

- 添加后端 OTA 服务和路由测试。
- 执行 Python 编译、定向 pytest、前端生产构建和 shell 语法检查。
- 仅暂存本次文件，创建分支、提交、推送并使用 PAT 创建 GitHub PR。

## 5. 追加用户需求

- 公开评分人列表接口与“查看评分人”弹窗，返回昵称、用户名、分数和时间。
- access token 过期时自动使用持久化 refresh token 重试请求，减少重复登录。
- 比赛作品响应携带 `soup_title`，比赛详情用汤名替代内部编号展示。
