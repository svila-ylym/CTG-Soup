# Turtle Soup Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair the active SQLModel/FastAPI stack and deliver a tested turtle-soup detail workflow with reveal, half-step ratings, idempotent likes/favorites, and first-level comments.

**Architecture:** Keep `backend/app/models/models.py` as the only model source. Use thin API routes over focused soup services, repositories, policies, and cache adapters. Keep Vue detail orchestration separate from API clients and presentational interaction/comment components.

**Tech Stack:** Python 3.9+, FastAPI, SQLModel/SQLAlchemy, PostgreSQL (SQLite test engine), Redis, Vue 3, TypeScript, Vite, Pinia, Vitest.

## Global Constraints

- TDD: every behavior starts with a failing test and is implemented minimally.
- Scope is the turtle-soup core and only startup/auth defects that block it.
- No unbounded comment nesting, rich-text comments, WebSocket, competitions, or search in this plan.
- Every interaction count update and unique record mutation is transactional and non-negative.
- Redis failures degrade ranking reads/writes to database behavior.
- Do not modify files outside `/root/project/CTG`.
