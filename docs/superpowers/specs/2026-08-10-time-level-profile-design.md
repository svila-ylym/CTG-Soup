# 时段风景、等级徽章与个人背景设计

## 目标

让首页风景随 UTC+8 时段变化；签到每次随机获得 5–15 经验并按每 100 经验升级；在帖子、评论和私信中显示带底框的等级徽章；个人主页支持上传并设置自定义背景图。

## 设计

- 首页用浏览器本地时间转换为 `Asia/Shanghai`，每分钟刷新时段 class：日出（06:30–07:00）、清晨薄雾（07:00–09:00）、中午（09:00–17:00，保持当前风景）、傍晚（17:00–19:00）、日落（19:00–20:00）、夜晚（20:00–次日 06:30）。CSS 负责天空色、雾层、日月和景观滤镜过渡。
- 等级采用 `floor(points / 100)`，等级 0 起算，下一等级为当前等级 + 1；每 10 级组成一档，颜色按黑、黄、紫、绿、铜、银、青、蓝、金、红映射，100 级以上保持红色。签到奖励使用 `random.randint(5, 15)`，不再随连续签到递增。
- 后端统一在 `UserSummary` 和公开个人资料中返回等级信息。前端新增 `LevelBadge`，在帖子列表/详情评论、私信会话与消息中展示，采用圆角、低对比度背景和阴影。
- 个人背景复用 `uploaded_assets` 图片上传；背景资源 ID 和 URL 写入已有 `users.notification_prefs` JSON（键 `profile_background_asset_id`、`profile_background_url`），不改表结构。个人资料页只展示公开 URL，设置页提供选择、上传和移除。

## 约束

- 不新增依赖，不产生数据库迁移。
- 图片仍经过现有上传接口和资源所有权校验。
- 第三方/本地时间和图片失败时保留可用的默认 UI。
