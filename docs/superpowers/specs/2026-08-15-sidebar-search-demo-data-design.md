# 侧栏搜索与演示数据设计

## 目标

优化移动侧栏搜索区，并为当前 SQLite 测试环境创建可登录的 root 账号和足够覆盖首页、汤列表、排行榜、论坛与比赛页面的关联内容。

## 界面

- 搜索区使用独立液态玻璃面板。
- 第一行只放搜索图标与输入框，输入框使用更明显的内侧高光、聚焦边框和柔和阴影。
- 第二行使用全宽“搜索”按钮，保留箭头图标；空查询时禁用。
- 浅色和深色模式使用现有玻璃变量，不改变搜索路由和抽屉关闭逻辑。

## 数据

- root 登录账号固定为 `root` / `RootTest!2026`，邮箱为 `root@test.local`。
- 额外创建 2 个普通测试用户、6 碗不同题材与汤色的海龟汤、5 篇帖子、评论、评分、点赞、1 场进行中的比赛、参赛条目和 1 条公告。
- 种子脚本只接受 SQLite 数据库，避免误写生产 PostgreSQL。
- 数据使用固定用户名和标题；重复运行时更新已有记录并补齐缺失关系，不重复堆积。

## 验证

- 运行前端生产构建。
- 执行种子脚本后检查各表数量。
- 通过 HTTP 验证 root 登录、首页、汤列表、排行榜和帖子列表。
- 不运行 TDD 或浏览器测试。
