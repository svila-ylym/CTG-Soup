# Redis、缓存与加载体验优化设计

## 目标

版本提升至 1.5.0。修复当前 Redis 缓存未实际生效、故障时反复阻塞、缓存键不稳定和模式删除阻塞等问题；优化问卷数据查询和前端加载体验；修复问卷页毛玻璃、圆角及按钮组合样式；让个人主页背景遮罩在暗色模式下使用黑色半透明模糊层。

## 范围

- 重构 `backend/app/utils/cache.py`，提供可降级、可测试、稳定序列化的同步 Redis 缓存适配器。
- 为问卷列表和详情建立显式缓存，不缓存用户私有状态、数据库会话或 ORM 对象。
- 在问卷写操作后执行有边界的缓存失效。
- 将问卷列表中的逐项统计查询改为聚合查询。
- 优化问卷列表和详情的首次加载、后台刷新及页面切换反馈。
- 统一毛玻璃组件的背景、边框、圆角、裁切和无模糊支持时的降级样式。
- 修复个人主页背景遮罩的暗色模式颜色。
- 将项目版本更新为 1.5.0。

不在本次范围：全站接口缓存、Redis 排行榜重构、异步 Redis 客户端迁移、服务端渲染或完整前端设计改版。

## Redis 与缓存架构

缓存适配器继续保持 Redis 可选。客户端使用连接池和短连接/读取超时；首次连接或命令失败后进入短暂冷却期，冷却期内直接返回缓存未命中，避免每个请求重复等待。成功连接后恢复正常状态。异常仅记录不含凭据的结构化警告，业务始终可回退数据库。

缓存值统一编码为 UTF-8 JSON。只接受可序列化的 Pydantic/字典/列表/标量数据，不使用 `default=str` 静默吞掉类型错误。默认 TTL 来自配置，显式 TTL 必须为正数。键使用命名空间和结构版本：

- `ctg:v1:surveys:list:<digest>`：摘要由规范化的 `page`、`page_size`、`status` 和可见性范围生成。
- `ctg:v1:surveys:detail:<survey_id>`：只缓存所有普通用户均可见的活跃问卷。

列表缓存需要区分普通用户与管理视图，防止非活跃问卷越权泄露。详情接口先完成数据库中的存在性、状态和权限判断，再决定是否读取或写入公共缓存。

模式删除不使用 `KEYS`，改为分批 `SCAN` 并按批次删除。缓存接口保留安全降级语义：读取失败等同未命中，写入或删除失败返回 `False`，不改变业务事务结果。

## 数据流与失效

列表请求先构造稳定缓存键，命中后返回 JSON 数据；未命中时使用聚合查询一次获取问卷及问题数、回答数，构造响应数据后写入短 TTL 缓存。详情请求仅对公开活跃问卷使用缓存。

写操作遵循先提交数据库、后清缓存：

- 创建或更新问卷：清理全部问卷列表键，并清理该问卷详情键。
- 提交回答：清理全部问卷列表键以及相关统计派生数据；详情本身不含回答计数时不必清理。
- 缓存清理失败只影响短期新鲜度，由 TTL 最终收敛，不回滚数据库提交。

## 查询优化

问卷列表当前对每条问卷分别查询问题数和回答数，并通过加载全部记录计算总数。改为数据库 `COUNT` 查询总数，并用分组子查询或聚合联接批量获得两个计数，消除 N+1 查询及不必要的数据加载。

聚合结果在写入缓存前转换为响应模型可接受的普通数据，确保缓存命中与数据库路径返回相同结构。

## 前端加载体验

问卷列表和详情首次加载显示与最终布局尺寸接近的骨架结构，减少布局跳动。分页或刷新时保留已有内容，仅在控件或内容区域显示轻量忙碌状态，并禁止重复请求。失败时保留已有数据并展示可恢复的错误提示；无既有数据时才显示完整错误状态。

页面过渡避免使用需要等待旧页面完全离场的模式，减少路由切换期间的空白。遵守 `prefers-reduced-motion`，骨架动画在减少动态效果时停用。

## 毛玻璃、圆角与个人主页遮罩

玻璃样式使用 CSS 自定义属性统一亮暗主题的透明背景、边框、阴影与圆角。容器使用背景裁切，保证圆角边缘正确；在支持 `backdrop-filter` 时启用模糊和适度饱和度，不支持时使用更不透明的降级背景。玻璃按钮不再覆盖主按钮的品牌背景和文字对比度；交互动画只应用于可点击卡片和按钮。

问卷页面增加能让半透明材质可感知、但不改变整体品牌的低对比度背景层。暗色主题使用深色玻璃变量。

个人主页背景图遮罩在亮色主题保持浅色半透明模糊层，暗色主题切换为黑色半透明模糊层，确保文字对比度和背景图片观感。

## 错误处理与兼容性

- Redis 未安装、未配置、超时、连接断开、值损坏或序列化失败时回退数据库。
- 损坏缓存值视为未命中并尝试删除该键。
- 缓存日志不得包含 Redis URL、密码、令牌或完整用户数据。
- 缓存不会改变现有认证与授权顺序。
- 亮暗主题、移动端、无 `backdrop-filter` 浏览器和减少动态效果偏好均有明确降级路径。

## 验证
