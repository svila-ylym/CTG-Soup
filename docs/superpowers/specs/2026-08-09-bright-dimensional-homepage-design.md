# 明亮立体风景首页设计

## 目标

把当前以普通文字和列表为主的首页重构为明亮、轻快、有纵深的社区入口。核心视觉由立体标题和多层风景组成，动效丰富但不牺牲信息可读性、移动端操作或低动态偏好用户的体验。

## 视觉方向

整体采用白昼插画质感，不使用暗黑霓虹、赛博朋克或压抑色调。主色仍以品牌蓝为中心，搭配天空蓝、湖水青、草地绿、日光黄和少量珊瑚橙。

首屏从后向前分为天空光晕、远云、远山、中景山丘、湖面、近景草坡六个景深层级。所有景物均由 CSS 和页面内 SVG 绘制，不依赖外部图片，也不增加静态大图下载。

“汤吧社区”使用大字号立体字：字面采用明亮渐变和高光，向右下方叠加多层挤出阴影，保留清晰轮廓与足够对比度。副标题和按钮保持简洁，避免立体效果影响正文阅读。

## 页面结构

### 1. 立体风景首屏

首屏采用左右布局。左侧包含社区标识、立体主标题、简短说明、两个主要按钮和三项社区能力入口；右侧是一组位于风景中的“谜题便签”，展示提问、线索和真相的推理节奏。窄屏时改为上下布局，便签数量和景物细节减少。

风景层必须使用 `pointer-events: none`，不能遮挡按钮和链接。首屏最低高度随视口变化，但不得在手机端强制占满导致下方内容难以发现。

### 2. 社区能力区

将原有“发现海龟汤、一起讨论、参加比赛”改造成三张错层纸片卡。每张卡包含图标、标题、说明和明确入口，视觉上像放置在风景前方的纸板，但保持扁平文字区域以保证阅读。

### 3. 热门海龟汤区

继续使用现有排行榜接口和数据，不改变请求逻辑。前六道汤使用带排名标识的立体卡片展示。前三名使用金、银、铜强调，其余统一使用品牌蓝。卡片包含标题、谜面摘要、分数、评分人数和作者，不虚构统计数据。

加载状态改为与主题一致的汤碗/光环动画；错误或空数据继续提供清晰的静态文案。数据加载失败不能影响首屏和社区能力区。

## 动画系统

动效由 CSS 动画、CSS 过渡和少量 Vue 状态控制完成，不引入 GSAP、Motion 或其他动画依赖。

### 首次进入

- 风景层由远到近依次淡入并向上归位。
- 主标题逐字弹入，字面高光随后扫过一次。
- 副标题、按钮和能力提示按 80–120ms 的间隔交错出现。
- 右侧谜题便签从不同方向进入，随后进入幅度很小的悬浮循环。

### 持续环境动画

- 云层以不同速度水平移动，循环衔接不可产生明显跳变。
- 日光光斑缓慢呼吸，湖面高光横向扫动。
- 远山几乎静止，中景和近景做低幅度漂移，形成景深。
- 桌面端根据指针位置给各景物层添加不同幅度的视差；指针离开后平滑回正。
- 手机端不监听指针，改为固定的低幅度自动漂移。

### 交互动画

- 主要按钮悬停时轻微上抬、阴影加深，图标向前移动；按下时快速回落。
- 社区能力卡和热门汤卡悬停时上抬、轻微旋转归正，并显示边缘高光。
- 热门汤数据出现时按卡片索引交错入场。
- 页面内锚点滚动使用平滑滚动，但不得覆盖用户的减少动态效果偏好。
- 全局路由切换由单纯透明淡入升级为轻微上移、缩放和透明度组合，时长控制在 260–360ms。

## 性能与无障碍

- 只动画 `transform` 和 `opacity`；背景色、阴影和滤镜仅用于低频交互，不做高频大面积循环。
- 装饰 SVG 必须标记为隐藏于辅助技术，交互元素保留可见焦点样式。
- 文本与背景必须保持足够对比度，立体标题的阴影不能降低字面辨识度。
- `prefers-reduced-motion: reduce` 下关闭逐字弹跳、循环漂移、视差和平滑滚动，只保留不超过 120ms 的透明度反馈。
- 小于 `640px` 时隐藏部分云层和最前景装饰，减少模糊和阴影，避免移动设备持续合成过多图层。
- 组件卸载时必须移除指针监听与动画帧，不能留下全局事件。

## 文件边界

- `frontend/src/views/HomeView.vue`：首页结构、排行榜数据、指针视差状态和首页局部动画样式。
- `frontend/src/assets/main.css`：可复用的路由过渡、按钮反馈、减少动态效果规则和平滑滚动规则。
- 不修改后端接口、数据库模型或排行榜 Store 的数据语义。

首页场景保持在一个页面组件内，避免为纯装饰层拆出过多小组件；复杂的风景图形通过语义清楚的分组和局部 CSS 管理。

## 验证方式

- 运行 `npm run build`，验证 Vue 类型检查和生产构建。
- 运行 `git diff --check`，验证补丁格式。
- 静态检查首页所有路由入口、按钮、加载/空状态和减少动态效果规则。
- 按用户要求，不运行浏览器或 Playwright 测试。

## 明确不做

- 不使用暗色霓虹或赛博风作为首页主视觉。
- 不引入外部图片、视频、Canvas 粒子系统或新动画库。
- 不修改导航功能、身份验证、排行榜接口或后端数据。
- 不把高强度循环动画扩散到所有业务页面。
