# 液态玻璃与页面动效设计

## 目标

在不改变业务 API 和页面结构的前提下，统一按钮、顶栏、移动侧栏与排行榜顶部区域的日夜主题视觉，并增加轻量鼠标拖尾和全局加载动画。

## 视觉与交互

- 复用全局玻璃变量，按钮增加高光、透明边框、背景模糊和按压反馈；深色模式切换到低亮黑色玻璃。
- 顶栏改为粘性毛玻璃表面，搜索框、通知按钮、发布按钮和用户菜单使用同一套液态玻璃层次。
- 移动侧栏保留现有抽屉结构，增强背景模糊、内侧高光和主题相关阴影。
- 首页移除“一碗汤，一群人，一场从为什么开始的推理冒险……”默认句，恢复 Hitokoto JSON 一言；外部接口失败或超时时回退为“每一条线索都算数”。
- 排行榜头部、分类切换和前三名卡片改用日夜两套玻璃表面，浅色保持可读的浅色背景，深色使用黑色玻璃和降低亮度的装饰。
- 桌面精细指针设备显示一个主液态光点和有限数量的衰减拖影，所有节点忽略鼠标事件；触屏和减少动态效果设置下关闭。
- 首次进入显示带品牌图标与液态波纹的全屏玻璃加载层；后续路由切换显示顶部液态进度条，并保留现有页面淡入。

## 实现边界

- 主要修改 `App.vue`、`NavBar.vue`、`HomeView.vue`、`LeaderboardView.vue`、独立拖尾组件和全局 CSS。
- 不新增前端依赖，不改业务 API 合同，不执行浏览器测试或 TDD。
- 动画只使用 CSS transform/opacity 和 `requestAnimationFrame`，限制拖尾节点数量，避免持续布局抖动。
- 所有动画遵守 `prefers-reduced-motion`，加载层设置最长显示保护，路由错误时也会退出加载状态。

## 验证与运行

- 运行前端类型检查与生产构建。
- 使用 SQLite URL 创建独立测试数据库并执行表初始化与基础健康检查。
- 启动后端和前端，分别监听 `0.0.0.0:10001` 与 `0.0.0.0:10000`。
