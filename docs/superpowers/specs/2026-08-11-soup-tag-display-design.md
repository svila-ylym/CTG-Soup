# 海龟汤标签展示设计

## 目标

让海龟汤列表保持紧凑，同时确保用户能在详情页查看发布时选择的全部系统标签和自定义标签。

## 展示规则

- 列表卡片最多显示 `soup.tags` 中的前 3 个标签。
- 标签总数超过 3 个时，在标签行末尾显示省略号，并通过提示文本说明剩余标签数量。
- 详情页在流派和汤色下方展示 `soup.tags` 中的全部标签，允许自然换行，不截断标签名称。
- 海龟汤没有标签时，不渲染标签区域或省略号。

## 数据与边界

前后端现有海龟汤响应已经返回完整 `tags` 数组，本功能不修改数据库、迁移或 API 契约。列表页和详情页只负责采用不同的显示策略。

## 错误处理

标签属于海龟汤详情和列表响应的一部分，不增加独立请求。接口加载失败时沿用页面现有错误状态；缺失或空标签数组按无标签处理。

## 验证

- 前端生产构建通过。
- 列表页模板只渲染前 3 个标签，并在第 4 个及以上存在时渲染省略号。
- 详情页遍历完整标签数组，不使用切片或行数截断。
- 后端完整测试继续通过，确认本 PR 中其他接口变更没有回归。
