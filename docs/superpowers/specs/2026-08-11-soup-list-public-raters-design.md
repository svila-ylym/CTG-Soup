# 汤列表公开评分人弹窗设计

## 目标

用户无需进入汤详情页，即可在海龟汤列表查看某个汤由哪些人评分、每人评分多少。信息全局公开，应用版本继续保持 `1.3.1`。

## 交互

- 每张汤卡片在现有平均分旁显示评分人数和“查看评分人”按钮。
- 点击按钮阻止卡片点击冒泡，不跳转汤详情页。
- 列表页只挂载一个评分人弹窗，通过当前选中的汤 ID 和汤名切换内容。
- 弹窗展示评分人的昵称、用户名、评分和评分时间，每页 50 条，提供上一页与下一页。
- 加载中、无评分、接口错误均有明确状态；关闭后再次打开另一碗汤时不显示上一碗汤的旧数据。

## 组件边界

- 新建 `frontend/src/components/SoupRatingsDialog.vue`，负责公开评分数据的加载、分页、错误状态和弹窗展示。
- 组件接收 `open`、`soupId`、`soupTitle`，关闭时发出 `close` 事件。
- `SoupListView.vue` 负责选择汤和打开/关闭弹窗，不复制数据加载逻辑。
- `SoupDetailView.vue` 改用同一组件，删除原有内联评分人弹窗及其重复状态/请求函数；评分提交逻辑保持不变。

## 数据与安全

- 继续调用现有公开接口 `GET /api/turtle-soups/{id}/ratings?page=<n>&page_size=50`。
- 不新增认证要求、不改变后端响应和排序规则。
- 前端只展示接口已有的昵称、用户名、分数和时间，不展示邮箱或其他私密字段。
